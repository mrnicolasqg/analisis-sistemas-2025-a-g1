# Gestor de Tareas

Proyecto final para la materia de **Análisis de Sistemas**  
Desarrollado por: **Nicolás Quintero García**  
Fecha: **Mayo 2025**

---

## 📌 Descripción

Esta aplicación permite **gestionar tareas personales** de forma sencilla, permitiendo al usuario:

- Crear nuevas tareas
- Ver todas las tareas guardadas
- Eliminar tareas completadas

---

## 🧱 Tecnologías utilizadas

- **Backend:** Node.js + Express
- **Frontend:** HTML, CSS y JavaScript
- **Base de datos:** Archivo JSON (`tareas.json`)
- **Herramientas:** Visual Studio Code, Postman, Trello
